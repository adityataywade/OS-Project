Using OS Lab Studio

01
Choose a simulator

Use the left navigation to open CPU scheduling, memory, disk, deadlock avoidance, semaphores, or file allocation.

02
Change the inputs

Try the sample data first. You can edit process details, reference strings, cylinder requests, or resource matrices.

03
Run and interpret

Use the Gantt chart, frame table, head path, and safety sequence to explain the algorithm in your viva.

Important: This is an educational simulator. It demonstrates OS algorithms; it does not modify your computer's actual scheduler, RAM, or disk.
